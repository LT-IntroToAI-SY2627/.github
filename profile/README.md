# Introduction to AI — Lane Tech College Prep
Mr. Berg | 2026-2027

## Welcome to Introduction to AI! 🤖

This course bridges the gap between Programming 1 and Programming 2 while diving into the exciting world of Artificial Intelligence. You will learn Python programming, work with real developer tools, and contribute to a class-built AI-powered app that grows all year long.

## Quick Course Overview

**What you'll learn:**
- Python programming with an AI focus
- GitHub version control and collaborative development
- Object-oriented programming principles
- Data structures and algorithms
- Machine learning and neural networks
- How to use generative AI as a professional tool

**Class format:** Mix of discussions, unplugged activities, hands-on coding, and a shared class project
